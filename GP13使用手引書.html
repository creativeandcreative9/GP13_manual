買った服を、こわさないか心配ですか。 メッシュ工房は、元のメッシュを書き換えません。 失敗しても、もどせます。 直した形は、アバターのビルドのときに入ります。

買った服は、そのまま残る

直した形は、元のメッシュとは別のファイルに入ります。 シーンや Prefab を保存するときは、表示を元のメッシュにもどします。 これは、初めの設定です。 そのため、編集中の形が Prefab に入りません。

メッシュ編集を追加すると、Assets の GP13_MeshKoubo_DataFile フォルダに、別のファイルができます。

失敗しても、もどせる

Ctrl+Z で、1 手ずつもどせます。 ［破棄］を押すと、編集を始めたときの形にもどして、編集を終えます。 途中で［保存］した分も、もどります。 長く作業しても、重くなりにくいしくみです。

［破棄］は、［保存］の右にあります。

保存後も、登録したシェイプキーのスライダーで元の形と切り替えられます。編集を続けるときは、編集済みライブラリから服を開きます。

確定する前に、くらべて決める

確定する前なら、半径や左右対称を変えられます。 変えると、同じ動かし方のまま、形が作り直されます。 いくつかの形をくらべてから、決められます。

［設定］タブの［頂点の表示と操作］を開きます。 ［ハンドルを離しても確定しない（ドラッグを維持）］をオンにします。 決めたら、［確定］を押します。

うまくいった設定を、取っておく

範囲やブラシの設定に、名前をつけて残せます。 ファイルに書き出せば、別のパソコンでも使えます。

［設定］タブの［プリセット］を開きます。 ［この名前で保存］と［呼び出す］を使います。 ［ファイルに書き出す］と［ファイルから読み込む］もあります。

アップロードすると、直した形になる

NDMF が入っていれば、アバターのビルドで、直した形が自動で入ります。 手元のアバターは変わりません。 NDMF がなくても、Play モードとビルドで入ります。 これは初めの設定で、自動で入れない設定にもできます。 アップロードの前に、［仕上がりをシーンに表示する］で同じ形を見られます。

やり方は「アップロードで直した形にする」にあります。

直したメッシュを、書き出す

直した形を、メッシュとして書き出せます。 シェイプキーつきと、形を焼き込んだ物の 2 通りです。 メッシュ工房を持っていない人にも渡せます。 渡してよいかは、元の服の利用規約で決まります。 FBX と OBJ に書き出せば、Blender で続きができます。

［出力］タブの［メッシュを書き出す…］を使います。 保存先を選ばずに服へ入れるなら、［レンダラーに書き込む］を押します。 FBX と OBJ は、［FBX / OBJ のファイルで書き出す］の中にあります。

気をつけること: FBX は、FBX Exporter が入っているときだけです。 OBJ には、ボーンもシェイプキーも入りません。 編集データは、配らないでください（元のメッシュの写しが入ります）。

服が新しい版になっても、形を移す

元のメッシュの点の並びが変わったら、直した形を新しい並びに移します。 移せなかった点の数は、警告に出ます。

気をつけること: 移すのは、シェイプキーの動きだけで、近い形になります。

Unity だけで、終わる

ウェイトもスカルプトも、Unity の中で終わります。 ふだんの編集には、追加のパッケージも VRChat SDK も要りません。 FBX で書き出すときだけ、FBX Exporter を入れます。 Unity 2022.3 と Unity 6、BRP・URP・HDRP で動きます。 手引書には、手順ごとの画像があります。

3D 創作スタジオを入れる

メッシュ工房は、3D 創作スタジオの統合パッケージに入っています。メッシュ工房の全機能は、完全無料です。

  1. BOOTHのメッシュ工房の無料ダウンロードから、最新版の統合パッケージを入手します。
  2. ZIPを展開し、中の 3D_CreativeStudio_v2_3_3.unitypackage を開きます。
  3. Unityの取り込み画面で［Import］を押します。
  4. 取り込みが終わったら、［Tools > Mesh Koubo > Open］を選びます。

窓の上に工房の切替バーが表示されれば、準備完了です。直したい服を選び、最初の3ステップへ進みます。

はじめての練習

スカートの裾をつかんで下げます。 下げた形をシェイプキーに登録して、スライダーで出し入れします。 練習なので、どんな服でも大丈夫です。 元の服は書き換わりません。 シーンビューにマウスを置き、ホイールを回すと拡大・縮小できます。

［映す］を押すと、シーンビューにその服が映ります。

服を選ぶのをやめるときは、［選択解除］を押します。 ［服(Mesh)］が空になり、ヒエラルキーの選択も外れます。 登録していない変更があるときは、先に登録するかを聞かれます。［設定］でオフにすると、確かめずに捨てます（Ctrl+Zで戻せます）。

  1. シーンビューで、スカートの裾にマウスを置き、下へドラッグします。

シーンビューの下の帯に、今使える操作が出ます。

つかんだ所がマウスについてきて、まわりもなめらかに下がります。 左がつかむ前、右がつかんで下げたあとです。

この画像では、裾を約 7 cm 下げました。動いた頂点は 290 個です。

  1. ［名前］に、形の名前を入れます。

  2. 光っている［シェイプキーに登録］を押します。

  1. 窓の下の［登録した形］で、スライダーを左右に動かします。

0 にすると元の形、100 にすると登録した形になります。 左がつかむ前、まん中がスライダー 50、右が 100 です。

［ハサミ］タブ

布に切れ目を入れます。 切った片側をつかんで開いたり、片側を隠したりできます。

  1. ［ハサミ］タブを押します。

  2. シーンビューで、切りたい線に沿って、布の上をドラッグします。

押した所から離した所までが、赤い点線になります。 線の両側は、緑とオレンジの点で分かれて見えます。

切るのは、線が通った所の、手前に見えている布だけです。 この画像では、スカートの前だけが切れて、後ろは切れませんでした。

  1. ［ここで切る］を押します。

［ボタンなど小さな部品は切らない］がオンだと、服から離れた小さな部品は切りません。 切りたい部品が切れないときは、オフにします。

  1. ［ウェイト］タブを押します。

  2. シーンビューで、体の動かしたい所（太ももなど）をクリックします。

  • シーンビューで、体の動かしたい所をクリックする。
  • 窓の［一覧から選ぶ］を押して、一覧から選ぶ。

［一覧から選ぶ］では、腰・胸・左の太ももなどの骨が先に並びます。 それ以外の骨は、［ほかの骨］の中にあります。

このドレスは、おもに胸の骨について動きます。 そのため、左の太ももを選ぶと、点はすべて青になりました。

プログラムで、自動にする

画面でする直しの多くは、C# のスクリプトからも呼べます。 同じ直しを、何着にもくり返すときに便利です。 プログラムを書かない人は、この章を飛ばしてかまいません。

何着ものめり込みを、ボタン 1 つで直す

服が何着もあると、1 着ずつ直すのは手間です。 下のスクリプトを置くと、Unity のメニューに項目がふえます。 押すと、メッシュ工房をつけて体を決めた服を、順に調べます。 めり込みの点があれば直して、保存します。

using GP13.Editor.Api;
using UnityEditor;
using UnityEngine;

public static class MeshKoboBatch
{
    [MenuItem("Tools/メッシュ工房の例/全部の服のめり込みを直す")]
    static void FixAll()
    {
        foreach (var target in MeshEditApi.Targets())
        {
            if (target.body == null) continue; // 体が決まっていない服は飛ばす
            var edit = MeshEditApi.Begin(target);
            var before = edit.Session.CheckPenetration().Count;
            if (before > 0) edit.Session.FixPenetration();
            var after = edit.Session.CheckPenetration().Count;
            Debug.Log($"{target.name}: {before} → {after}");
            edit.SaveAndClose();
        }
    }
}

中では、画面の［貫通をチェック］と［自動修正］と同じしくみを呼びます。 直した形は、「貫通修正」のシェイプキーに入ります。 数は、めり込んだ点と、近すぎる点の数です。

実アバターの服 3 着で、この例を 1 回動かしました。 コンパイルのエラーは、ありませんでした。 メニューを押すと、パーカーは 50 個から 0 個に、ワンピースは 536 個から 0 個になりました。 体を決めていないブーツは、飛ばされました。

スクリプトは、Assets の中の「Editor」という名前のフォルダに置きます。 メニューの Tools に、項目が出ます。

［体のレンダラー］に同じアバターの体を指定します。編集中なら、保存してから進めます。自動修正のあとも、［つかむ］やブラシで気になる箇所を仕上げられます。

編集のコツと使い分け

作業に合う機能を選び、仕上がりを確認しながら進めます。書き出し形式や姿勢の確認など、迷ったときの使い分けをまとめました。

ゼロから作る・ほかのアバターに移す

  • 衣装を、別のアバター向けに変換することはしません。 着せたあとの「あと少し」を直す道具です。
  • 服や小物を、ゼロから作ることはできません。 点を足す・消す・複製することはできます。 面を自由につなぐ機能や、メッシュをくっつける・別のメッシュに分ける機能はありません。 線を引いて切り分けることはできます（［ハサミ］タブ・［メッシュ切断］タブ）。
  • 色・模様・UV は変えられません。
  • ボーンを、新しく作ったり、消したりはできません。
  • 左右に移すときは、中心と反対側を探す距離を設定し、元の形と片側ずつ比べます。
  • 格子で囲んで変形する機能や、面・UV を選ぶ機能はありません。 画面は、日本語・English・한국어 を切り替えられます。手引書は、日本語だけです。

揺れ・動き

  • スカートの揺れや、歩いたときのめくれは直せません。 揺れ物（PhysBone）の設定などを見直します。 ウェイトを変えると、揺れが小さくなることがあります。
  • 揺れている最中のめり込みは、調べません。 まとめて調べるのは、決まった 7 つのポーズです。
  • 布のモードは、形を作るための引っぱりです。 アバターの中で揺れたり、ぶつかったりはしません。
  • 座らせたまま、点をつまんで直すことはできません。 ポーズで見て、立った姿で直します。

全部おまかせ

  • 座ったときなどの大きなめり込みは、自動修正に［つかむ］やウェイト調整を組み合わせて仕上げます。複数の姿勢を見ながら、好みの強さを決めます。
  • 服が体から浮いたすき間は、自動では調べません。 自動で詰める機能もありません。 手で詰めるなら、ブラシや点の移動を使います。
  • 体型のスライダーに服がついてくる形を、ボタン 1 つでは作れません。 体のシェイプキーを服へ読み込む手順を、自分で行います。
  • 布で引っぱっても、伸びが収まらないことがあります。 表面に沿った距離で測ると、つながっていないリボンなどは、ついてきません。
  • AI が自動で直す機能はありません。

軽さ・アップロード

  • ポリゴン数を減らす機能です。ボーンやマテリアルの数を整えるときは、それぞれの設定を使います。
  • Quest 向けの変換はしません。 PC 版と Quest 版で、別の直し方にする設定もありません。
  • FBX で書き出すには、FBX Exporter が要ります。 OBJ には、ボーンもシェイプキーも入りません。
  • VRChat のメニューは作りません。 作れるのは、シェイプキーをオン・オフするクリップです。
  • 表情トラッキングや口パク用のキーを、自動で作る機能はありません。 自分で形を作ったり、ほかのメッシュのキーを読み込んだりはできます。

動く場所

  • 動くのは、Unity のエディタの中だけです。 アップロードしたアバターの中では動きません。
  • 対応環境はUnity 2022.3／Unity 6のEditorです。配布パッケージを入れたプロジェクトで編集します。

保存・更新・配る

  • ［保存して終了］のあとは、Ctrl+Z で戻せません。 保存の前なら、戻せます。
  • 衣装を新しい版に替えたとき、直した内容が全部移るわけではありません。 移せるのは、シェイプキーの動きです。
  • もとからある表情のキーは、直接は書き換えません。 直した物は、新しいキーとして増えます。
  • 編集データには、元のメッシュの写しが入ります。 人の衣装を含めて、配らないでください。 受け取る人にも、元の衣装とメッシュ工房が要ります。

編集中は、ポリゴンタブの調整も Ctrl+Z で1つ前に戻せます。 Ctrl+Y でやり直せます。 調整の前後で、動かした形や選んだ点も一緒に戻ります。 履歴は編集中に使えます。［保存して終了］の前に戻してください。

［元のメッシュに戻す（リセット）］は、ポリゴン調整をまとめてやめる操作です。 消えた点の移動量などは、近くの面から求め直します。 1つ前と同じ状態に戻すときは、Ctrl+Z を使います。 リセット自体も、編集中は Ctrl+Z で取り消せます。

戻せる回数には、上限があります

戻す履歴は、変わった頂点だけを覚えます。 そのため、大きなメッシュでも、1 回分が小さくて済みます。 ポリゴン調整のように、頂点の数が変わる操作は、前と後を、まるごと覚えます。 戻せるのは、最大 200 回分です。 覚えておく大きさにも、上限（約 256 MB）があります。 超えると、古い操作から順に、戻せなくなります。 大きさの上限を超えても、いちばん新しい 1 回分は残ります。 この上限は、画面では変えられません。

数値で動かす・押し出す

ドラッグでは、細かい量を決めにくいことがあります。 数字で入れれば、決めた量だけ動かせます。 面の向きに沿って動かすと、服を少し外へふくらませたり、内へへこませたりできます。 この章は［くわしく］の画面で行います。先に、「［くわしく］で始める」の手順で、服の編集を始めておきます。 付け方は、「はじめての練習」にあります。 動かしたい頂点は、「つながった部品を選ぶ」の方法で、選んでおきます。

  1. ［頂点］タブで、［数値入力・押し出し・なめらかにする］を開きます。

  2. ［移動 (m)］に、動かす量を入れます。

    X・Y・Z の向きの量です。単位は、メートルです。

  3. 回したいときは、［回転 (度)］に、角度を入れます。

  4. 大きさを変えたいときは、［拡縮］に、倍率を入れます。

    1 で変わらず、2 で 2 倍、0.5 で半分です。

  5. ［適用］を押します。

    使わない欄は、そのままにします。

  6. 面の向きに沿って動かすときは、［量 (m)］に、動かす量を入れます。

    プラスなら外へふくらみ、マイナスなら内へへこみます。0.01 は、1 cm です。

  7. ［押し出す］を押します。

  2. ［X］をオンにします。

    名前が、［左右対称（オン）］に変わります。

  3. 体の中心がずれているときは、［対称の境目の位置］を直します。

  4. ［反対側の探し方］で、［仮想の点］か［実際の頂点］を選びます。

  5. ［実際の頂点］を選んだときは、［対応づける距離 (m)］を決めます。

［仮想の点］は、選んだ場所を鏡に映した位置にも、同じ範囲で動きを足します。 反対側に、対応する頂点が無くても、使えます。 ［実際の頂点］は、鏡に映した位置にいちばん近い頂点を探して、動きを当てます。 左右の頂点が、対になっているメッシュ向けです。 基本の左右対称は、「左右を同時に直す」にあります。

気をつけること

  • 頂点を選んでいないときや、数字が変わらない値のときは、変形されません。メッセージが出ます。
  • ［対称の境目の位置］と［対応づける距離 (m)］は、服に合わせて決めます。

継ぎ目で割れないようにする

動かしても、縫い目で服が割れないようにしたい

服の継ぎ目（縫い目）では、同じ位置に、頂点が重なって分かれていることがあります。 メッシュ工房は、同じ位置にある頂点を、1 つとして扱います。 そのため、継ぎ目の両側の頂点が、同じ量だけ動きます。 継ぎ目が、開きにくくなります。 この章は［くわしく］の画面で行います。先に、「［くわしく］で始める」の手順で、服の編集を始めておきます。 付け方は、「はじめての練習」にあります。

継ぎ目をこえて、選んで動かします

  1. シーンビューの設定の窓で、［頂点］を選びます。

  2. L キーを押しながら、部品の上の頂点を、クリックします。

    継ぎ目で分かれていても、同じ位置にある頂点は、ひと続きとして選ばれます。

  3. 選んだ頂点の、緑の矢印を、ドラッグします。

    継ぎ目の両側の頂点には、同じ動きが加わります。

頂点の選び方は、「つながった部品を選ぶ」にあります。 矢印の使い方は、「スカートの丈を伸ばす」にあります。

めり込みを直したあとも、確かめます

［自動修正］で直すときは、「めり込みを直す」と同じです。 直したあとは、継ぎ目の所を、前と後で見比べます。

気をつけること

  • 同じ位置とみなす距離は、0.00001 m です。
  • 左右対称は、別の機能です。継ぎ目を守るための、専用のボタンではありません。
  • 継ぎ目の位置や、ウェイトの付き方によっては、割れないとは言い切れません。動かしたあとは、継ぎ目の所を、見て確かめます。
C# API・HTTP API・EESで自動化する

繰り返し行う編集は、スクリプトや外部のツールから操作できます。画面の操作と同じ編集データを使います。

  • C# API：Unity Editor内のスクリプトから操作します。
  • HTTP API：起動したUnityへ要求を送り、対象・形・保存を操作します。
  • EES：Editor Eyeから、短いC#で画面の操作を呼び出せます。

詳細な使い方は、配布物の Documentation/README.md を入口に、API-ja.md、HTTP-API-ja.md、EES-ja.mdをご覧ください。

困ったとき

続きを進めるためのヒント

どのファイルを入れればよいですか？

BOOTHで無料ダウンロードした3D 創作スタジオのZIPを展開し、中の.unitypackageを取り込みます。導入の3ステップをご覧ください。

メッシュ工房が見つかりません

Unityの［Tools > Mesh Koubo > Open］を選びます。別の工房を開いている場合は、上部の［メッシュ工房］へ切り替えられます。

直したい服を選べません

Hierarchyで服を選ぶか、アバターのルートを選んでから［服(Mesh)］の一覧で対象を選びます。ルートと服を選び直すときは［選択解除］を使います。

別のパーツまで動きます

［囲む］で直したいところだけ選びます。つながった部品単位で選ぶ方法や、範囲のぼかしも使えます。範囲を囲んで選ぶへ進んでください。

自動修正のあとに、手で仕上げたい

［つかむ］へ移り、気になるところをドラッグします。手で変えた形は［シェイプキーに登録］で残します。自動修正の形とは分けて強さを決められます。

編集を終えたあと、結果はどこで見られますか？

服を選び、Inspectorの［Mesh Edit］→［仕上がり］で登録した形を出し入れできます。［編集済みライブラリ］から編集した服を開くこともできます。

元に戻したい

直前の操作はCtrl+Zです。登録した形を消して比べるときはシェイプキーを0にします。［くわしく］で編集全体をやめる場合は［破棄］を使います。戻し方をご覧ください。

NDMFが入っていません

［レンダラーに書き込む］で、編集済みメッシュの写しを服に割り当てられます。元FBXは変わりません。書き込みの手順をご覧ください。

アップロードへ、どの方法で反映しますか？

NDMFがある場合は［ビルドのときに当てる］を［自動］にします。NDMFを使わない場合は［レンダラーに書き込む］で反映します。2つの経路から選べます。

衣装を更新しました

編集データを残したまま、［対象の設定］の［元のメッシュ］を更新後のものへ切り替えます。衣装更新の手順で、形を確認しながら進めます。

どこまで無料で使えますか？

メッシュ工房は全機能・回数制限なしで無料です。きがえ工房は最初の1着、保存呼出し工房は1スロット無料。Proは2着目以降の着せ替えと、保存スロット無制限を解放します。

きがえ・保存呼出しへ移るには？

窓の最上部にある工房名を押します。ポーズ・メッシュ・きがえ・ボーン・色ツヤ・保存呼出しの6工房を切り替えられます。連携の手順をご覧ください。

症状別の詳しい対処

困ったとき

［かんたん］で、服をつかんでも動かない

  • どうなっているか: 動かせない所をつかんでいます。理由は、シーンビューの下の帯の赤い行と、窓の［つかむ］タブの注意に出ます。
  • どうすればよいか: 出た理由を読みます。「ここはロックされています」なら、［くわしく］でロックを外すか、ロックしていない所をつかみます。「ここは［ハサミ］などで切り分けた範囲の外です」なら、範囲の中をつかむか、［全体を編集する］を押します。

［かんたん］で、つかむと角ばって動く

  • どうなっているか: つかんだあたりの頂点が少ないです。「ここは頂点が少ないので、角ばって動きます」と出ます。
  • どうすればよいか: Ctrl+Z で戻し、［細かくする］を押してから、もう一度つかみます。くわしくは「［かんたん］と［くわしく］」の章の「粗い服は、［細かくする］」を見てください。

［かんたん］で、マウスほど服がついてこない

  • どうなっているか: 服が体やほかの服に当たったか、面が裏返りそうなので、そこで止めています。シーンビューの下の帯に、理由と「ついてきた割合」が出ます。
  • どうすればよいか: 止まった所までの形でよければ、そのまま登録できます。やり直すときは、Ctrl+Z で戻します。

別のツールで着せ替えたあと、窓に知らせが出た

  • どうなっているか: メッシュ工房で直したあとに、別のツールなどで、服のメッシュや骨が入れ替えられています。窓とインスペクターの上に「この服は、メッシュ工房で編集したあとに、別のツールなどでメッシュや骨が入れ替えられています。今の服をそのまま使い、前の編集は当てていません。」と出ます。入れ替えたあとの服は、そのまま守られます。
  • どうすればよいか: 今の服を直すときは、［今の服から編集を始める］を押します。今の服のメッシュを元にして、新しく編集を始めます。前の編集データは消えずに残りますが、今の服へは自動では移りません。直さないときは、［メッシュ編集を外す］を押します（当てる編集が無いときだけ出ます）。服はそのまま変わりません。どちらも Ctrl+Z で戻せます。

練習に、Cube などで試したい

  • どうなっているか: 服でなくても、メッシュを持つ物なら編集できます。Unity の上のメニューの［GameObject > 3D Object］で作った Cube・Sphere・Plane・Quad・Capsule・Cylinder も使えます。
  • どうすればよいか: メッシュ工房の窓を開いたまま、ヒエラルキーで Cube などの行を選ぶと、編集が始まります。アバターの服を使わずに、操作を試せます。

エラーのお知らせが出た

多くのお知らせは「結果」「理由」「対処」の順に書いてあります。まず結果で、どこまで進んだかを確かめます。理由に書かれた対象をヒエラルキーとインスペクターで確認し、対処を行ってから同じ操作を試してください。

「編集できるメッシュが見つかりません」か「選んだ物には、編集できるメッシュがありません」と出たら、服や体の行を選び、Skinned Mesh Renderer の Mesh 欄、または Mesh Filter の Mesh 欄にメッシュが入っているか確かめます。Mesh Renderer だけでは編集を始められません。

切断時に「切断する辺に3枚以上の面」と出たら、重なった面などがあるため切断は行われていません。元のメッシュの重なった面やつながりを直してから、もう一度切ってください。

タブの中身が灰色で、使えない

  • どうなっているか: まだ編集を始めていません。
  • どうすればよいか: ［くわしく］の画面かインスペクターで、［編集を開始］を押します。

点が選べない・見つけにくい

  • どうなっているか: 点が多く、重なっています。
  • どうすればよいか: ホイールで拡大して選びます。

裾をひと回り選べない

  • どうなっているか: Alt+クリックで、足りない所が出ることがあります。
  • どうすればよいか: Shift を押しながらクリックして足すか、ドラッグで囲みます。

めり込みが直らない

  • どうなっているか: 重ね着や、両立しないポーズがあります。
  • どうすればよいか: 外側の服で試します。尖ったら Ctrl+Z で戻します。素材に体を隠す形がある場合は、素材の手引書も見ます。

座ると、服が太ももにめり込む

  • どうなっているか: 太ももの動きに、服の裾がついていっていません。
  • どうすればよいか: ［かんたん］なら、［ウェイト］タブの［体に合わせる］を押して、強さを決めます（「［ウェイト］タブ」）。［くわしく］なら、「脚についてくるように直す」の［プリセットで設定する］が、同じおすすめの設定です。どちらか 1 つを使います。足りない所は、太もものウェイトをブラシで塗ります。

布として引っ張っても、ついてこない部品がある

  • どうなっているか: 分かれた部品（リボンなど）は、ひと続きの服ではありません。
  • どうすればよいか: その部品は、頂点タブで別に動かします。

布が大きく伸びたままになる

  • どうなっているか: 保護がオフか、何度も伸ばしています。伸びの保護は1回の操作ごとです。
  • どうすればよいか: Ctrl+Z で戻し、小さく引きます。不要なピンは［ピンを外す］で外します。

布がマウスの位置まで動かない

  • どうなっているか: ［伸びすぎ・折り返しを抑える］が移動を制限しています。［動かせた割合］で量が分かります。
  • どうすればよいか: 小さく引くか、ピンを見直します。保護を外す場合は、貫通や面の裏返りを確かめます。

保存のあと、Unity の矢印が出た

  • どうなっているか: 服全体を動かす矢印です。
  • どうすればよいか: さわりません。さわったときは、Ctrl+Z で戻します。

スライダーを動かしても、形が変わらない

  • どうなっているか: 「仕上がり」の下のチェックが、オフかもしれません。
  • どうすればよいか: オンにします。［ビルドのときに当てる］が［自動では当てない］のときも、表示されません。

編集中のシェイプキーのスライダーが使えない

  • どうなっているか: ●の行は、編集中の形を 100 の状態で見せています。
  • どうすればよいか: ●を押して○に戻してから、スライダーを動かします。

シェイプキーの名前が分かりにくい

  • どうなっているか: 自動の名前です。
  • どうすればよいか: シェイプキータブの一覧で、名前を書きかえます。

アップロードした姿に、直した形が出ない

  • VRChatアバターをNDMFなしでアップロードする場合は、［レンダラーに書き込む］で反映します。UnityのPlayや、ワールド・ゲームのビルドでは［自動］の設定で適用されます。
  • どうすればよいか: 「アップロードで直した形にする」を見て、書き出します。

保存せずに閉じてしまった

  • どうなっているか: 保存した内容は、同じ場面（シーン）で確かめます。
  • どうすればよいか: シーンを開き、［仕上がり］で確かめます。
  • 次からは、閉じる前に［保存］か［保存して終了］を押します。編集がファイルに書き込まれます。

上のメニューに［Tools > Mesh Koubo］が出ない

  • どうなっているか: ツールがまだ入っていないか、Unity の読み込みが終わっていません。
  • どうすればよいか: 画面右下の読み込みの印が消えるまで待つか、「入れ方」を見て取り込み直します。

MeshKobo の窓にドロップしても、追加されない

  • どうなっているか: メッシュ（服の形）が入っていない親の行などをドロップしています。
  • どうすればよいか: ヒエラルキーで左の ▶ を押して中を開き、直したい服そのものの行（SkinnedMeshRenderer や MeshFilter が付いた行）をドロップします。

Add Component に「Mesh Edit」が出ない

  • どうなっているか: ツールが、Unity に入っていません。
  • どうすればよいか: 「入れ方」を、もう一度やり直します。

プロジェクトウィンドウに GP13_MeshKoubo フォルダが出ない

  • どうなっているか: ZIP ファイルをまだ解凍していないか、取り込みの窓で［Import］を押す前に閉じたかもしれません。
  • どうすればよいか: 入れ方に戻り、3D_CreativeStudio の .unitypackage を取り込み直します。

取り込んだあと、Unity に赤いエラーが出た

  • どうなっているか: 以前の Assets/MeshKobo フォルダや古いツールのファイルが残っているか、同じツールが別の方法でも入っているかもしれません。
  • 最新版の統合パッケージを取り込みます。更新の手順は更新するときをご覧ください。

ポリゴン調整をやり直したい

  • どうなっているか: 三角形の数を変えたり、点を消したりしました。
  • どうすればよいか: 編集中は Ctrl+Z で、調整前の状態へ戻せます。戻しすぎたら Ctrl+Y でやり直せます。
  • ［元のメッシュに戻す（リセット）］は、消した点を周りの面から求め直します。1手戻す操作とは違います。
  • 編集を始めてからの変更をすべてやめるときは、［破棄］を使います。

  • プロジェクト: Unity で作業しているデータの入れ物です。
  • ヒエラルキー: Unity の左にある、置いてある物の一覧です。
  • インスペクター: Unity の右にある、選んだ物の設定の窓です。

服の言葉

  • メッシュ: 服の形そのもののデータです。

  • ポリゴン: 服の表面をつくる三角形です。

メッシュ工房の言葉

  • ［かんたん］・［くわしく］: 窓の 2 つの画面です。［かんたん］は、やりたいことのタブを選ぶだけの画面です。［くわしく］は、すべての道具が並ぶ画面です。
  • 動く範囲: ［かんたん］で服をつかんだとき、いっしょについてくる範囲です。
  • 登録した形: ［シェイプキーに登録］で残した形です。窓の下に並び、スライダーで出し入れできます。
  • 突き抜け: 体が服を突き抜けて、外から見えてしまうことです。［突き抜け］タブで調べて直します。
  • 部分: ［ハサミ］や［メッシュ切断］で切り分けた、服の一部です。部分ごとに動かしたり、隠したりできます。
  • リング: 切る線を、袖やスカートを一周するように広げたものです。［切り込み線をリング状に広げる］で作ります。

  • プリセット: 設定を保存して、また使えるようにしたものです。
